# Интеграции — что реально доступно (проверено 2026-10-24)

| Инструмент | Статус | Что даёт |
|---|---|---|
| vidIQ MCP: `vidiq_ig_profile`, `vidiq_ig_profile_reels` | ✅ работает | Публичный профиль + 12 последних Reels (просмотры, лайки, комментарии) |
| vidIQ MCP: `vidiq_ig_accounts_from_outliers`, `vidiq_instagram_tiktok_outlier_search` | ✅ работает | Поиск конкурентов и вирусных форматов |
| vidIQ MCP: `vidiq_instagram_owner_insights` | ⛔ не подключено | Охваты, сохранения, репосты, досмотры. Нужно: профессиональный аккаунт + подключение Instagram в app.vidiq.com |
| vidIQ MCP: `vidiq_instagram_publish_reel` | ⛔ не подключено | Публикация Reels. **Используется только после явного «публикуй» от владельца** |
| Google Calendar / Drive / Gmail MCP | доступны в сессии | Календарь публикаций, хранение материалов (пока не используем) |
| Meta Graph API напрямую | не настроено | Альтернатива vidIQ; требует Meta-приложения и токена — не делаем без необходимости |

Правила: не запрашивать пароли, cookies, токены, 2FA-коды; ничего не публиковать, не отправлять сообщения и не менять профиль без подтверждения.
